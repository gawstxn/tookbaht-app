# Security

Tookbaht handles people's personal finances, so security reports are very welcome.

## Reporting a vulnerability

Please report privately, not in a public issue or pull request:

- **GitHub:** [Report a vulnerability](https://github.com/gawstxn/tookbaht-app/security/advisories/new) (Security tab → Advisories), or
- **Email:** the contact address on the app's [privacy policy](https://tookbaht.gawstxn.dev/privacy).

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within a few days, and a fix is released as soon as it's ready; tell me if you'd like to be credited.

## Scope

In scope: the app at `tookbaht.gawstxn.dev`, this repository's code, and its database policies (row-level security, grants, SQL functions).

Please don't access other people's data, run denial-of-service or automated scanning against production, or social-engineer anyone. Test with your own account, or run the app locally (see the README).
